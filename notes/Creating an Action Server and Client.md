## Action Server

1. Choose the action name and create a custom interface.
2. Import the interface and create an action server.
3. While creating the server register at minimum the goal and execute callbacks plus an optional cancel callback.
4. Implement the callback functions.

## Action Client

1. Choose the action name and the already created interface.
2. Import the interface and create an action client.
3. Add a goal sending method.
4. Implement at least a goal response and result callback and an optional feedback callback if required.
