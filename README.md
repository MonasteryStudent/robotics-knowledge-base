# Robotics Knowledge Base

A personal robotics knowledge base designed to be used with [Obsidian](https://obsidian.md/).

The vault documents my learning journey in robotics and the current focus is on **ROS 2**.

The knowledge base may expand over time to cover additional robotics topics such as kinematics, motion planning, control, and perception.

To use the knowledge base as intended, open the repository folder as an Obsidian vault.
