# Robotics Knowledge Base

A personal robotics knowledge base designed to be used with [Obsidian](https://obsidian.md/).

The vault documents my learning journey in robotics, including **ROS 2** and the foundations of **autonomous robots**.

The knowledge base may expand over time to cover additional robotics topics.

To use the knowledge base as intended, open the repository folder as an Obsidian vault.

## References

- *ROS 2 from Scratch* by Edouard Renard
- *Introduction to Autonomous Robots* by Nikolaus Correll et al.
